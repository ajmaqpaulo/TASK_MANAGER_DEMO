
# 💻 TASK_MANAGER_DEMO (Frontend)

Bienvenido al repositorio del cliente web. Este proyecto es la interfaz gráfica construida en **React** que interactúa con el backend de tareas y el microservicio de autenticación.

---

## 📂 Documentación

Si necesitas ver los prototipos, diseños o flujo de pantallas, revisa la carpeta `01_DOCUMENTACION` (si aplica en tu estructura actual).

---

## 🛠️ Requisitos Previos

Asegúrate de tener instalado:
* Node.js > 20.17.0
* Tener los servicios de Backend corriendo (`BACKEND_TAREAS` y `MICROSERVICIO_AUTH`).

---

## ⚙️ Instalación y Configuración

Sigue estos pasos para preparar el entorno visual:

### 1. Instalar dependencias
El proyecto utiliza librerías como **axios** para comunicarse con los servicios y **React Router** para la navegación. Instala todo con:

```bash
npm install

Run `npm run dev` to start the development server.
